## 1.1

```python
# Determine if a string has all unique characters

def is_unique(s):
    # Create a set to store unique characters
    char_set = set()
    # Iterate through the string
    for char in s:
        # If the character is already in the set, return False
        if char in char_set:
            return False
        # Add the character to the set
        char_set.add(char)
    # If the program has reached this point, all characters are unique
    return True

# Test the function
print(is_unique('a'))  # True
print(is_unique('abcda'))  # False
print(is_unique('abcde'))  # True
print(is_unique('aabbcc'))  # False
print(is_unique(''))  # True
```

The set works with Unicode code points. It uses linear time in the expected case and linear auxiliary space in the worst case.

What if you **cannot use additional data structures**?

Compare each character with every character after it. This takes $O(n^2)$ time and $O(1)$ auxiliary space. If a fixed-size table is allowed and the input is ASCII, there are only 128 possible character values. A 128-entry Boolean table gives an $O(n)$ scan, and a string longer than 128 characters must contain a repeat.
